# Khanate Cozy — pixel-art life sim (v0.1)

Небольшой браузерный 2D-проект на **Phaser 3** в эстетике «уютной степной стоянки» с оригинальным стилем, вдохновлённым мотивами Казахского ханства.

## Что внутри

- Одна локация 40x30 тайлов: степная земля, тропинки, трава.
- Объекты: киіз үй (юрта), ошақ (костёр), сандық (сундук), құдық (колодец), лавка.
- Игрок с 4 направлениями движения и анимацией ходьбы + лёгкое idle-«дыхание».
- Коллизии с объектами.
- Взаимодействие рядом с объектами (`E — Әрекет` / `E — Действие`).
- NPC (саудагер/торговец) с простым диалогом из нескольких реплик.
- Атмосферный цикл день/вечер через плавный overlay.
- Минималистичный HUD + помощь + переключение языка KZ/RU.
- Все ассеты (тайлы, объекты, персонажи, UI-элементы) генерируются **программно** в `src/main.js` через `Phaser Graphics -> generateTexture`.

## Управление

- **Движение:** `WASD` или `Стрелки`
- **Взаимодействие:** `E`
- **Помощь:** `H`
- **Язык:** `K` (KZ), `R` (RU), либо кнопка `KZ/RU` в HUD

## Локальный запуск

> Нужен любой простой HTTP-сервер (без сборки и без npm).

### Вариант 1: Python

```bash
python3 -m http.server 4173
```

Откройте: `http://localhost:4173`

### Вариант 2: VS Code Live Server

Откройте репозиторий и запустите `Open with Live Server` для `index.html`.

## Деплой на GitHub Pages (main + root)

1. Запушьте проект в ветку `main`.
2. В GitHub: **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/(root)`
4. Сохраните и дождитесь URL вида:
   - `https://<username>.github.io/<repo>/`

## Стек
